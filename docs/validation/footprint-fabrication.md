# Live footprint fabrication edits

This independent change adds `edit_footprint_fabrication` to `pcb_components`. It addresses assembly attributes and deliberate pad paste settings without requiring a library refresh that could replace unrelated instance content. It is based directly on J3Techs main and does not include other open tool changes.

The tool binds the exact open PCB and footprint reference. Inspection is read-only; changes default to a dry run. Apply requires a hash of the target path, complete footprint and requested edits. Duplicate references, missing or unexpected physical pad counts, unknown wire data, invalid values and nonpositive aperture dimensions refuse before mutation. Pad paste edits specify both absolute and relative values, symmetrically for the two sides; explicit zeros differ from inheritance.

Each apply uses one IPC undo commit. Complete-footprint readback occurs after EndCommit. Unexpected post-write state reports `uncertain`, without claiming rollback; unchanged state after failure is separately reported. The document is not saved automatically. No file fallback is available.

KiCad 10.0.6 added parent fields for pads (13), board text (6), and footprint instances (17), which the vendored schema lacked. The KiCad-authored fixture exposed that omission under the lossless-edit guard. This change adds only these verified read-only parent fields from [KiCad 10.0.6 board_types.proto](https://gitlab.com/kicad/code/kicad/-/raw/10.0.6/api/proto/board/board_types.proto). Newer unsupported fields continue to refuse instead of being discarded.

Regression coverage uses an existing KiCad-authored footprint fixture and a staged IPC server that publishes edits only at EndCommit. It checks mounting-only preservation, explicit zero paste, pad-count and aperture refusal, unknown wire data, duplicate references, revision binding, stale requests without writes and truthful uncertain state after a corrupted readback.

Final local gates passed: formatting, clippy with warnings denied, 1,842 workspace library/integration tests, eight doc tests, and the executable build. Five negative controls individually disabled the pad-count, aperture, unknown-pad-wire, stale-plan and post-commit-readback guards. Each caused its regression test to fail; the exact source was restored and all seven focused tests passed again.

Live KiCad 10.0.6 on macOS accepted inspection and dry-run plans for eleven footprints. Eleven mounting-style edits and explicit zero paste margins on four same-number thermal pads completed through IPC with full readback. After save, independent native reads verified the intended SMD attributes, all four paste ratios, unchanged effective paste dimensions, and unchanged physical pad geometry, nets, routing, layers, thickness and model assignments. DRC remained at zero errors and zero unconnected items. A first inspection refused before mutation while the missing parent fields were being diagnosed; no fallback was used. Windows, Linux and newer KiCad versions have not been observed locally. Stencil suitability, supplier acceptance and finished-board performance are outside this tool's contract.
